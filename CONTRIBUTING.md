# Contributing

Welcome contributors. Thank you for helping improve Headless WP Theme.

## How to contribute

1. Open an issue for bugs, ideas, or larger changes.
2. Keep changes small and focused.
3. Follow WordPress coding, escaping, and internationalization practices.
4. Avoid remote assets, tracking, and plugin-like functionality.
5. Test PHP files with `php -l` before submitting.

## Pull request checklist

- The change is useful for a lightweight WordPress theme.
- Public strings are translation-ready.
- Output is escaped where needed.
- No third-party asset is added without license and source details.
- Documentation is updated when behavior changes.

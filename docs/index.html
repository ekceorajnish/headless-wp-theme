Headless WP Theme

Free headless CMS WordPress theme for teams using WordPress as a CMS backend with a custom frontend.

Use it for headless WordPress projects, REST API CMS setups, Next.js frontends, Jamstack sites, static frontends, and lightweight WordPress publishing workflows.

Download Theme View on GitHub

Features

  • Free to use under the MIT License
  • Lightweight classic WordPress theme
  • Built for headless CMS WordPress projects
  • Accessible skip link and keyboard focus styles
  • No tracking and no remote resources
  • Open for contributors
